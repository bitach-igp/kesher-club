## As built
- `src/api.ts` gains `FunderApi.memberships()` (`GET /memberships`) and `cancelMembership(id, key)`
  (`POST /memberships/{id}/cancel`), and the `MembershipRow` type. P13 shows only the funder's rows; the membership a
  funder holds themselves is not billing they manage.
- Each row: "For {name}" (the member's display name as written, or "For a member"), the plan code, the price, and one
  line: renews on a date, ends on a date once cancelled, ended, paused, or past due as a sentence asking for a new card.
  The API sends no plan name on a membership, so the plan reads by its code until the catalogue names it.
- Cancel is two taps in place: the first shows the confirm (runs to the end of the paid period, no further charge, the
  money already loaded stays the member's) with "Yes, cancel" and "Keep it"; nothing is sent until the second. A
  cancelled row offers no Cancel.
- One Idempotency-Key per membership's cancel, kept until it succeeds, so a retry after a 503 is the same cancel. A 409
  (ended), 403 or 404 reads as a sentence and re-reads the list so the row says why.
- Dates read as "December 10, 2026" or "10 בדצמבר 2026" through `intlLocale`.
- `family.tsx` gains a "Memberships and billing" link to `/funder/billing`, routed from the screen so `family.model.ts`
  stays untouched.
