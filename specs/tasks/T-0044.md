It (1) runs `roles.sql` as the RDS master user (managed master secret), (2) sets the passwords of `club_app`, `club_jit`, `club_readonly` and `club_migrator` from Secrets Manager (new containers `db-jit-password`, `db-migrator-password`, `db-readonly-password`), (3) runs `node db/migrate.mjs` as `club_migrator`. Idempotent, safe to run on every deploy, exits non-zero on any failure, never logs a password or a URL with one. Tests: `migrate.test.mjs` plans the three steps in order and refuses a missing secret; `terraform test` asserts the task runs in the private subnets with no public IP and its role can read only those secrets.
