# T-0528 [PAY] Member app binds the device: Pay, Card, eSIM and Emergency open instead of throwing
REQ: REQ-PAY-001, REQ-ESIM-001 (after T-0033) · Sprint: 11
Files: apps/mobile/src/web-device.ts, apps/mobile/src/web-device.test.ts, apps/mobile/src/device.ts, apps/mobile/app/_layout.tsx, apps/mobile/app/_layout.test.tsx, specs/tasks/T-0528.md, specs/tasks/README.md
Test first: TST-PAY-001 (screen rows), TST-ESIM-001 (screen rows). Found while recording REC-05 (T-0920): the root layout never mounted a `DeviceProvider`, so every screen that reads the device (`app/pay/index.tsx`, `app/card/index.tsx`, `app/club/esim.tsx`, `app/help/emergency.tsx`) threw "DeviceProvider is missing" as soon as it opened. Their screen tests passed because each test injects `fakeDevice()`. The root layout now builds the device with the other root dependencies and mounts the provider. The tests cover: a screen that reads the device renders under the root layout (and fails without the provider); a phone's browser reports its own platform and OS version, so the eSIM install steps and the one-tap rule follow the phone; a desktop browser is `web` and cannot hold an eSIM; location maps a denial to `denied` and a missing API or timeout to `unavailable`; the clipboard writes through the browser.
Done when: listed tests pass; `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm trace` green; only listed files touched
Out of scope: native bindings (expo-location, expo-clipboard, a camera scanner, the contact picker): those modules are not in the app yet, and adding them is a dependency decision of its own. Stop and ask on conflict with the spec.

As built:
- The binding is the web build's, since the web build is what runs today (T-0033). `DeviceInfo.platform` gained `web` for a desktop browser; the one existing reader (`club/esim.model.ts`) never reaches the install steps for it, because a desktop browser is not eSIM-capable.
- No camera or contact picker on web: the pay screens already treat both as unavailable and offer typing a phone number instead.
