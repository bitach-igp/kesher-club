Files: apps/console/Dockerfile, apps/console/next.config.ts, apps/console/package.json, apps/console/src/config.ts, apps/console/src/config.test.ts, apps/console/app/healthz/route.ts, apps/console/src/boot.ts, apps/console/instrumentation.ts, apps/console/proxy.ts, apps/console/README.md, infra/terraform/envs/shared/variables.tf, handoff/desktop/T-0047-docker-build.md, docs/setup/deploy.md, .github/workflows/release.yml, infra/terraform/envs/staging/main.tf, infra/terraform/envs/prod/main.tf, infra/terraform/tests/markets.tftest.hcl, docs/setup/release.md, specs/tasks/T-0047.md, specs/tasks/README.md
Test first: `apps/console` is a Next.js server app (`proxy.ts` resolves the session on every request; the server holds the token pair in httpOnly cookies and calls the API), yet `envs/staging` and `envs/prod` host `console.<domain>` from a private S3 bucket behind CloudFront (`module.console`, the static-site module). A static bucket cannot run `proxy.ts` or server components, so the console cannot work there. It has no Dockerfile and `release.yml` builds only api, worker and admin. Build it like `apps/admin` (T-0915, T-0917: `output: 'standalone'`, one image for every environment, healthy only when configured, config crash on boot), add `kesher/console` to ECR (envs/shared) and to `release.yml`, and run it as an ECS service on the PUBLIC ALB at `console.<domain>` (institution staff are not on the VPN), health path `/healthz`, CloudFront in front only if the cache rules keep every response uncached. Remove `module.console`, its S3 bucket and its Route 53 alias. Env: `CONSOLE_ENVIRONMENT`, `CONSOLE_API_URL` (IL API; the console picks the market from the institution). Tests: a misconfigured start exits with the reason (as T-0918); `terraform test` asserts a console service on the public ALB and no console bucket.
Done when: listed tests pass; `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm trace` green; CI's terraform job green when `infra/` changed; only listed files touched
Out of scope: the parent portal and marketing site (T-0048); WAF rule tuning beyond the existing ALB module. Stop and ask on conflict with the spec.
