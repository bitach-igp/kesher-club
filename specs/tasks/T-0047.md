A static bucket cannot run `proxy.ts` or server components, so the console cannot work there. It has no Dockerfile and `release.yml` builds only api, worker and admin. Build it like `apps/admin` (T-0915, T-0917: `output: 'standalone'`, one image for every environment, healthy only when configured, config crash on boot), add `kesher/console` to ECR (envs/shared) and to `release.yml`, and run it as an ECS service on the PUBLIC ALB at `console.<domain>` (institution staff are not on the VPN), health path `/healthz`, CloudFront in front only if the cache rules keep every response uncached. Remove `module.console`, its S3 bucket and its Route 53 alias. Env: `CONSOLE_ENVIRONMENT`, `CONSOLE_API_URL` (IL API; the console picks the market from the institution). Tests: a misconfigured start exits with the reason (as T-0918); `terraform test` asserts a console service on the public ALB and no console bucket.
