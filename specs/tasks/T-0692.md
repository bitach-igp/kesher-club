## As-built
- `SocialTokenRevoker.revokeForClosure(partyId, now)` in `apps/api/src/auth/social.ts` (same file as the sign-in service; no new file). It uses the T-0694 methods only (`SocialLinks.takeForRevoke`, then `eraseToken`): no new repository method, no migration. No stored token (Google only, passkey only, Apple link without a token, or already erased) is a no-op.
- Called from `ClosureService` in `settle`, after `setUserStatus('closed')` and the `account.closed` audit entry, so a refund that fails or is pending never revokes Apple access. It is also called on the `close()` path for an already closed member: closure is state-based and has no key, so this is how a retry mends a crash between the status and the revoke or the erase (with no token left it is one read).
- Revoke is `federatedIdp.revoke('apple', token, 'closure:{partyId}:apple-revoke')`. A failure (any throw, including an unsealable token or an unresolvable binding) does not block the closure: one `ops.case` of kind `apple_revoke_failed`, severity high, dedupe `apple-revoke:{partyId}`, payload `{ partyId, provider, failure }` where `failure` is the port's error code or `REVOKE_FAILED` (never a message, never the token); then the token row is erased. The case is written before the erase, so if recording it fails the token stays and a retry tries again. If the erase itself fails the error surfaces (the account is already closed) and a retry revokes again under the same key (a replay at the adapter), then erases.
- Wiring (shared plumbing, `apps/api/src/app.ts`): the PII cipher is now one `pii` const shared by `displayNames` and the new `SocialLinks`; `socialLinks` is added to `app.services` (T-0694 left it unwired); `ClosureService` takes a `revoker` dependency.
- Not covered: the real Postgres path of `identity.federated_token` under `club_app` (T-0694's desktop handoff); the OIDC adapter's call to Apple (its contract suite, T-0117). A closure that is never retried after a crash between status and revoke leaves the token until the member or support closes again; no sweep exists for it.
