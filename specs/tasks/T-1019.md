Design: Night Market is dark-native. Its cyan `#04F7E8` is 1.36:1 on white, so it cannot be the light-mode action; brand navy `#293B8F` is 9.9:1 on white, so it stays the light action. Night Market is therefore the DARK face and the light face is roughly "Direction B": one theme, two modes. Starting values (light / dark); `contrast.test.ts` is the gate and may move them:
- `color.bg.canvas` `#F4F7FB` / `#010235`
- `color.bg.surface` `#FFFFFF` / `#0B1247` (dark cards lift by tone, not shadow)
- `color.action.primary` `#293B8F` / `#04F7E8`
- `color.text.onAction` `#FFFFFF` / `#010235`
- `color.accent.cyan` `#293B8F` / `#04F7E8` (dark-led: `sd.config.mjs` `expandModes` requires a `$value` and the parity test requires identical paths in both modes, so a token cannot omit a mode; the light value is the navy action as a conservative STARTING VALUE and it ships as the light CSS variable, so say so in `$description`)
- new group `color.facet.*`: `blue` `#0558F5` / `#5B9DFF` (5.6:1 on white); `orange` `#9A4E00` / `#FC7D03` (the light value is darkened to 6.0:1); `magenta` `#A3006C` / `#FF4FC0` (`#E805A2` is 4.2:1 and fails); `yellow` light `#8A6D00` (a darkened yellow, STARTING VALUE, must pass 3:1 as a fill on `bg.surface`) / dark `#FAD206`, FILL ONLY, never text on white (an explicit light value is required, same rule as `accent.cyan`).
- The two ACTION values are FIXED: navy `#293B8F` in light, cyan `#04F7E8` in dark. Every other value in this list is a starting value that the gate may move.
- DEPENDENT DARK TOKENS the plan is silent on (still the old Jerusalem-stone slate and blue values, which would clash with navy `#010235` and a cyan action): `color.action.primaryHover` (dark `#B0CAFF`), `color.action.primarySubtle` (dark `#1B2B55`), `color.border.focus` (dark `#8FB4FF`), `color.bg.sunken`, `color.bg.stone`, `color.border.default`, `color.overlay.scrim` (based on `#0D1426`), `color.accent.blue` and `color.accent.sky`. RE-DERIVE each from the new navy and cyan, in both modes where the old value no longer fits; `contrast.test.ts` is the gate and decides the final values. Each one is LISTED in the contrast assertions (focus ring against canvas and surface at 3:1, hover and subtle fills against `text.onAction` / `text.primary` at 4.5:1, scrim against the text laid over it, `accent.blue` and `accent.sky` as the existing 3:1 non-text claims, the existing `accent.blue` `#1D76BB` and `accent.sky` `#9ADBF6` literal pins updated with the spec table).
