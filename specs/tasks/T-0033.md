# T-0033 [SETUP] The member app runs in a browser (Expo web) against the local stack
REQ: — (enabling; after T-0031) · Sprint: 10
Files: apps/mobile/app.json, apps/mobile/metro.config.js, apps/mobile/app/_layout.tsx, apps/mobile/app/_layout.test.tsx, apps/mobile/src/config.ts, apps/mobile/src/passkeys.ts, apps/mobile/package.json, apps/mobile/README.md, pnpm-lock.yaml, specs/tasks/T-0033.md, specs/tasks/README.md
Test first: the app has screens and view models but no Expo project: no `app.json`, no root `_layout.tsx`, no `expo` or `expo-router` dependency (apps/mobile/README.md, "the Expo project config … come with the first dev build"). So nothing can be opened, on a phone or anywhere else. This card adds the Expo project and the root layout that binds the seams the README names (`navigation.ts`, `session.ts`, `linking.ts`, `device.ts`, `passkeys.ts`, `sdkApi()`). `pnpm --filter @kesher/mobile web` serves it on localhost against `EXPO_PUBLIC_API_URL`. Passkeys on web use the browser's WebAuthn on `localhost`. In a development build only (`EXPO_PUBLIC_APP_ENV=development`, read at build time so Metro drops the branch from any other bundle), the binding uses `SimPasskeyDevice`, so a seeded persona signs in without a hardware key. What the API answers never switches it on: `_layout.test.tsx` also pins that a build with any other `EXPO_PUBLIC_APP_ENV` uses the platform authenticator even when the API sends the simulator's options. `_layout.test.tsx` (jsdom, react-native-web) renders the layout with a fake API and a fake session store: signed out it routes to `(auth)/sign-in`, signed in it routes to `(tabs)/home`. `src/config.ts` refuses a non-`https` API URL unless the host is `localhost`.
Done when: listed tests pass and the existing mobile tests still pass; `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm trace` green; `pnpm --filter @kesher/mobile web` opens sign-in in Chromium against the T-0031 process (stated in the PR with a screenshot); only listed files touched
Out of scope: native dev builds, EAS, store signing, Maestro flows, and new screens. Stop and ask on conflict with the spec.
