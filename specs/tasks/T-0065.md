## As-built
- `POST /admin/legal/documents` (`proposeAdminLegalDocument`, 201, or 200 with the request already made for the same document and text) and `POST /admin/legal/documents/{requestId}/approve` (`approveAdminLegalDocument`, 200). No reject or list (kept minimal). Neither takes an idempotency key (like the plan admin routes), so `HEADER_OPS` is unchanged.
- The request is `ops.approval_request` kind `legal_publish`, subject `legal_publish:{docKey}:{sha256 of key and both bodies}`, scope `platform`, the whole draft in `payload`. The proposer is the first of two approvers (as plan versions), so approving their own request is 409 `IDEMPOTENCY_CONFLICT`; a decided or expired request is also 409, and publishes nothing more.
- Approval and `LegalService.publish` and the audit entry (`legal_document.publish`, reason = the English change summary, else a default) run in one transaction, so a crash cannot leave an approved request that never published.
- Deviations from the Files line: the approvals kind check needed a migration (`0029`, forward-only, NOT VALID) and `ApprovalKind` / `approversRequired` / the admin-role check in `approvals/service.ts`. `atlas` is not installed here, so `atlas.sum` was regenerated with a script that reproduces the existing sums byte for byte; re-run `atlas migrate hash` and `pnpm db:lint` on the desktop, and the real-Postgres apply is not done (no handoff request committed).
- Every verified staff token carries the `admin` role (`StaffTokenVerifier`), so `requireStaff(req, 'admin')` rejects only non-staff sessions (403); there is no finer "non-admin staff" case to test.
- An effective date in the past is 422 at proposal; if the approval comes after the date the version is in force from the approval time (not retroactive).
- A text that was published, expired or rejected cannot be proposed again verbatim (the subject is unique per document and text); change the text or add a reopen flow.
- Unverified: behaviour on real Postgres (the tests run on PGlite); the admin console screen is out of scope.
