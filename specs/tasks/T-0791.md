# T-0791 [AUTH] Directory drift sweep: a worker job compares each SSO institution's WorkOS directory with `org.staff_idp_link` and deprovisions anyone the directory no longer lists as active
REQ: REQ-AUTH-008 (SECURITY: independent reviewer required, the author must not review it) · Sprint: later · after T-0790; behind `auth.orgSso` (the job runs only for a market whose `org-idp` binding exists and the flag is on)
Files: apps/worker/src/institutions/directory-drift.ts, apps/worker/src/institutions/directory-drift.test.ts, apps/worker/src/jobs.ts (one row in `buildJobs`), specs/tasks/T-0791.md, specs/tasks/README.md
Source: decision on T-0785 (2026-11-23). A webhook can be lost (WorkOS retries are finite, our outage, a replay window) and the 15-minute promise of REQ-AUTH-008 is then missed silently. `OrgIdPPort.listDirectory(orgId)` ("Directory snapshot for drift checks (nightly compare against local staff table)", `org-idp.ts`) was built for this and has no caller. Cadence: the port comment says nightly; to keep the 15-minute promise even if every webhook for an institution is lost, cycle every 10 minutes for institutions with at least one active link, and nightly for a full report of directory users with no link (information only, no action). WorkOS rate limits are respected by one list call per institution per cycle.
Test first: TST-AUTH-008, simulator org IdP: (1) a linked staff member the directory lists `active: false` is deprovisioned through the SAME shared removal as T-0790 (one audit row, sessions revoked) and a second sweep changes nothing; (2) a linked staff member absent from the directory is deprovisioned and flagged `drift_missing` in the audit payload; (3) an active directory user with no link, or a directory user inactive with no link, causes no change and is only counted; (4) `PROVIDER_UNAVAILABLE` from the port changes nothing and the job reports failure for the cycle (no deprovision on an outage; an empty list from a failed read must never be read as "everyone left": a guard refuses to deprovision more than half of an institution's linked staff in one cycle and opens a case instead); (5) the job is not run when `auth.orgSso` is off, and `jobs.test.ts`'s table-versus-files check passes with the new row; (6) a lag metric `staff.drift_corrected` is emitted.
Done when: listed tests pass; `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm trace` green; only listed files touched; about 250 lines. Needs an independent reviewer.
Out of scope: the webhook (T-0790); creating links (T-0792); the nightly unlinked-user report beyond a count; any flag change; WorkOS credentials (owner actions in T-0790).
