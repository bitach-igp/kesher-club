## As built
- `GET /institutions/{id}/members?status=&cohort=&cursor=` (`RosterMember` schema, `additionalProperties: false`)
  for any active staff role of the institution. Another institution's staff get 404; an unknown status or a cursor
  the API never gave answers 422.
- **Paging.** 50 a page, ordered by name then id, so a page boundary never repeats or drops a row when names tie.
  The cursor is opaque: base64url of the last name and id.
- **The row's fields:**
  - `cohort` is the member's latest placement (T-0636).
  - `card` is the best live card: active, then frozen, then inactive. Closed cards don't count.
  - `balances` are the wallet balance per currency, summed from the ledger's postings. That writes nothing, unlike
    `purses()`, which creates missing accounts. An invited member who hasn't joined has none.
  - `planCode` is the latest membership still running.
- **No spend.** The row type has no spend field at all, and the test pins the keys, so REQ-INS-005 holds by
  construction.
