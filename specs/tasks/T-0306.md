Test first: TST-BIL-002.
- **Invite (P04).** `POST /funder-invites` (Idempotency-Key): the member's name, a phone or an email, the plan code and the saved payment method. Needs the funder's approved T1 (403 otherwise). The plan's offered version is pinned on the invite.
- **Delivery.** NotifyPort sends the link (`https://app.kesher.example/join?token=`), SMS for a phone and email otherwise; only the token's hash is stored. Resend sends the same link again; cancel ends it.
- **Expiry.** 7 days, then `expired`; nothing is charged before the member accepts (T-0307). One open invite per funder and contact.
- **List.** `GET /funder-invites`: the funder's own invites with status (open, accepted, expired, cancelled).

- a T0 funder answers 403; a second open invite for the same contact answers 409; an unknown plan answers 422;
- 7 days later it reads expired; cancel and resend by another funder answer 404.

## As built
- **The card stays with the vendor.** The funder saves a card through `POST /me/billing/setup-sheet`, which makes their
  billing customer on first use (`MembershipService.ensureCustomer`, now shared with `create`). The invite stores no
  payment-method id: the subscription that T-0307 starts charges the customer's saved card. Without a saved card,
  inviting answers 422. `apps/api/src/billing/memberships.ts` is touched for that extraction.
- **Schema.** `billing/0003_funder_invite.sql` (the card's number). One open invite per funder and contact is a
  partial unique index. An open invite past its 7 days reads `expired` at once and is marked so when it would block
  a new one. Only the token's hash is kept; the funder's list shows the contact masked.
- **Resend** rotates the link, so an earlier one stops working, and keeps the first send's 7 days. **Cancel** ends it.
  Another funder's invite answers 404 for both.
- **Gates.** `billing.stripe` (FEATURE_OFF otherwise); the funder's approved T1 (403). No step-up, as for
  `POST /memberships`: nothing is charged here.
- `atlas.sum` was refreshed with a Node script that reproduces atlas's hash format byte for byte (both existing sums
  match), because the atlas binary could not be fetched in this session.
