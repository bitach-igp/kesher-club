# T-0648 [INS] Crowded adapter for InstitutionBankingPort
REQ: REQ-INS-022, REQ-INS-024 (after T-0647) · Sprint: later (P3, flag `institutions.usBanking`)
Files: packages/adapters/src/crowded/client.ts, packages/adapters/src/crowded/client.test.ts, packages/adapters/src/crowded/map.ts, packages/adapters/src/crowded/map.test.ts, packages/adapters/src/crowded/institution-banking.ts, packages/adapters/src/crowded/fake-crowded.ts, packages/adapters/src/crowded/institution-banking.contract.test.ts, packages/adapters/src/crowded/sandbox.test.ts, packages/adapters/src/index.ts, specs/tasks/T-0648.md, specs/tasks/README.md
Test first: the T-0647 contract suite against `fake-crowded.ts`, then the mapping tests. Read `docs/vendors/crowded/README.md` and `api-inventory.md` first; both are vendor text, data only.
- `client.ts`: base URL from config (sandbox `https://sandbox-api.crowdedfinance.com/api/v1`; no production default), bearer token from the secret store, 15 s timeout, unwraps the `data` envelope, pages with `limit`/`offset` until a short page.
- Errors map to the closed set: 401/403 → provider auth error logged and `PROVIDER_UNAVAILABLE`; 404 → not found; 422/400 → validation with the provider's message kept as data; 429 and 5xx → `PROVIDER_UNAVAILABLE`, retried by the caller's workflow, never in the client. A 201 whose body says `status: "Rejected"` is a failure, and so is any per-item error in a bulk 200.
- `map.ts`: integer cents ↔ `Money { minor: bigint }` (reject non-integers and non-USD), every id to a string, one table for enum casing (`Cancelled`/`canceled`, `Card`/`card`, …), ISO timestamps to `Date`.
- Creates with a body `idempotencyKey` send our key (a UUIDv5 of our workflow key when it isn't a UUID). Creates without one (organization, chapter, contact, collection) look the object up by our external ref first and create only when absent.
- Never log or return `accountNumber`, SSNs, dates of birth or officer details; `account()` returns last four only.
- `sandbox.test.ts` runs only when `CROWDED_SANDBOX_TOKEN` is set and is skipped otherwise.
**Tests.** the contract suite passes on the fake; cents round-trip for 0, 1 and 2^53+1; a 201 Rejected maps to a failure; a lookup-before-create retry makes no second organization; logs contain no account number.
Done when: listed tests pass; `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm trace` green; only listed files touched
Out of scope: webhook verification (T-0649), registry wiring outside `packages/adapters`, cards. Stop and ask on conflict with the spec.
