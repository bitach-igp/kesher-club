## As-built
- New `BalanceHero` (label, ILS and optional USD `Money`, formatted by `format(Money, intlLocale)`; one accessible summary line; `direction` set on web only) and `TabBar` (items with key, label, glyph; `role=tab` and `aria-selected` on the active one; each tab `minHeight` 44; the first tab sits at the reading start). `Badge` gains a `brand` tone. All three are exported from `components/index.ts`.
- Scope narrowed from the first draft of this card: `Screen`, `Banner` and `ListRow` are unchanged (they already use start/end edges, the existing source scans in `rtl.test.tsx` cover them, and `Toggle` already has `role="switch"`). Dropped from the card's list: a ListRow focus ring (React Native's `Pressable` has no portable focus state) and reduced motion (none of these primitives animates). If either is wanted, it is a new card.
- Direction: on native the row and hero mirror with I18nManager (no explicit `direction`, so a runtime locale switch cannot flip them ahead of the rest of the screen); on react-native-web they set `direction` from the locale.
- Tests are in `rtl.test.tsx`: bigint amounts beyond 2^53 render exactly in en and he, the hero reads as one line, the tab bar marks the active tab, calls back with the key, meets 44 points and mirrors, the brand badge renders. The existing scans (no left/right, no fixed sizes, font scaling on) now also run over the two new files.
- Nothing mounts these yet; T-0672 (home) and T-0673 (tab bar in the layout) use them.
