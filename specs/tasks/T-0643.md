## As built
- **Schema.** `org/0010_staff_invite.sql` adds insert-only `org.staff_invite` and `org.staff_invite_acceptance`.
  The address and the link's token are kept only as sha256 hashes; the message carries both. Desktop handoff:
  `handoff/desktop/T-0643-staff-invite.md`.
- **Endpoints.** The paths say `team` where the card said `staff`, because `/institutions/{id}/staff` is close to
  the admin console's `/admin/institutions/{id}/staff`.
  - `GET /institutions/{id}/team`: any staff role. Lists staff, open invites and grants waiting for a second
    admin.
  - `POST /institutions/{id}/staff-invites` (key): admins only. Takes email or phone, not both. Sent through the
    notify port.
  - `POST /staff-invites/{token}/accept`: the invitee, signed in, joins as staff at once. Expired, taken, or staff
    elsewhere answers 409.
  - `PATCH /institutions/{id}/team/{partyId}` (key): admins only. `role` or `active: false`.
  - `POST /institutions/{id}/staff-grants/{grantId}/approve`: admins only, with step-up.
- **Grants.** `finance` and `admin` land through a `staff_grant` on the shared approvals, scoped
  `institution:{id}`:
  - The proposer is the first approver: the inviter, when an invite is accepted, or the admin making a change.
  - The second is another admin of the same institution with a step-up. Neither the person granted nor the proposer
    can approve.
  - A single-admin institution's grant is listed in the admin console's existing grant queue, which already
    filters by institution. There a Kesher admin approves it (REQ-ADM-004).
- **Guards.** Nobody raises their own role (403). The last active admin cannot be removed or demoted (409).
  Removal deactivates the staff row, so the same token is refused on its next call. It also strips the org role,
  which leaves the token at the next sign-in.
- **Audit.** Every invite, proposal, grant and removal is audited.
- **Outside the card's list:** `approvals/service.ts` now lets `org_admin` decide a `staff_grant`, besides a
  Kesher admin. The team service checks that the deciding admin belongs to the grant's institution, and the admin
  console path still requires a Kesher admin.
