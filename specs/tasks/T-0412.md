## As built
- `controls.model.ts` sets online, ATM, where the card works and four refusable categories (gambling, alcohol, tobacco,
  adult), each a fixed set of merchant category codes; a category counts as refused only when all its codes are, and
  unblocking one keeps the codes the member refused on their own. Each change sends only its own key, so the API locks
  exactly that key for the member.
- Where it works is IL and US toggles or Anywhere (`allowedCountries: null`, which the server accepts and the
  generated type does not spell, so it is cast once). Switching off the last country is refused with a sentence
  rather than sent as "nowhere".
- Hand back sends `{ release: [key] }`; the value stays and the member may change it.
- One Idempotency-Key per distinct change, kept until that change succeeds: a 503 or a passkey prompt retries with
  the same key, and the next change takes a new one. Freeze sends no step-up; unfreeze answers `STEP_UP_REQUIRED`,
  shows the passkey banner, and the retry after `stepUpDone()` reuses its key.
- Refusals: NOT_FOUND (no longer the funder), FORBIDDEN, VALIDATION_FAILED (closed or not activated) and an
  unavailable provider each read as a sentence, in English and Hebrew.
- Limits and agent purchases stay out of P09 (agent purchases are REQ-CRD-008's own card).
