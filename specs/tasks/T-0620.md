Test first: TST-INS-011 (HTTP rows). Endpoints, each on a staff token:
- `GET /admin/institutions/{id}/kyb`: the current decision, the people, the latest check of each kind and person, and the open approval;
- `POST /admin/institutions/{id}/kyb/people`: add a board member, control person or signatory, keyed by an Idempotency-Key;
- `POST /admin/kyb/checks/{id}/dispose`: a false positive or a true match, with a note;
- `POST /admin/institutions/{id}/kyb/decisions`: an outcome, a risk rating and reasons, keyed;
- `POST /admin/kyb/decisions/{id}/approve`: the second reviewer.

Compliance and admin roles write; support reads. Names are staff-entered text, and phone numbers never appear. The tests cover the T-0619 rules over HTTP, including that a support token cannot decide and that a replayed key returns the same row.
