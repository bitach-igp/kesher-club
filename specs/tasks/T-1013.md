Test first: TST-AGT-001, TST-AGT-002 (HTTP rows). Found while recording REC-09 (T-0921): `McpGateway` (`apps/api/src/mcp/gateway.ts`) is built and passes `agentGatewayContract`, but no running process serves it, and no card ever planned that. The API serves:
- `POST /mcp` (Streamable HTTP, JSON-RPC);
- `GET /.well-known/oauth-protected-resource` with the gateway's metadata.

Both are behind `mcp.enabled`, with writes behind `mcp.write.enabled` and money proposals behind `mcp.money.propose`, as the gateway already enforces. The tests cover:
- an unauthenticated call answers 401 with the `WWW-Authenticate` challenge naming the metadata URL;
- a token for another audience is refused;
- `tools/list` with a read-scoped token lists only read tools;
- `propose_p2p` over HTTP creates a pending intent and no transfer;
- with `mcp.enabled` off, `/mcp` answers 404.

The demo stack mounts it too, and REC-09 can then propose through it instead of the stack helper.
