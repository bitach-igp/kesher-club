## As-built
- **Base image digest.** Fetched, not guessed: `sha256:dd9d21971ec4395903fa6143c2b9267d048ae01ca6d3ea96f16cb30df6187d94` is the OCI index digest of `node:22.22.0-bookworm-slim` from Docker Hub (`Docker-Content-Digest` of the HEAD, and the sha256 of the manifest body matches). All five Dockerfiles (api, worker, admin, console and `tools/migrate`, the card named four) use `FROM node:22.22.0-bookworm-slim@sha256:...`; `tools/release/release.test.mjs` asserts they are identical. The Atlas image in `tools/migrate` is still pinned by tag only (`arigaio/atlas:1.3.8`); a follow-up.
- **Admin image bug.** `apps/admin` imports `@kesher/tokens/css`, a generated file under `dist` that `.dockerignore` drops; its Dockerfile now runs `pnpm --filter @kesher/tokens build` before the app, as console's does. api and worker do not depend on `@kesher/tokens` or any other workspace `dist`, so they are unchanged. Not built here (no Docker).
- **Terraform.** `envs/shared`: `aws_inspector2_enable.ecr` and `aws_ecr_registry_scanning_configuration.this` (ENHANCED, SCAN_ON_PUSH, wildcard `kesher/*`); the repositories keep `scan_on_push = true`. `modules/oidc` gives the CI role `ecr:DescribeImageScanFindings`, `ecr:ListImageReferrers` and `inspector2:ListFindings` (account-scoped, tfsec-ignored like `GetAuthorizationToken`). There is no tftest for `envs/shared`, so none was added.
- **Workflow.** Syft (`anchore/sbom-action@v0.20.5`, CycloneDX JSON) then `oras attach` (`oras-project/setup-oras@v1`, oras 1.2.3), then a scan wait and the gate. The gate is `aws inspector2 list-findings` filtered by image digest, repository, CRITICAL, fixAvailable YES and ACTIVE, passed to `tools/release/check-findings.mjs` with the ignore list.
- **Exceptions.** `.github/security/image-scan-ignore.json` (empty), rules in `docs/setup/release.md`; tests in `tools/release/release.test.mjs`, added to the root `test` script.
