Test first: TST-INS-008. Institutions may run allowances on credit (decision 2026-10-20), but only up to a limit Kesher set on purpose. Each institution has a credit limit per currency: ₪0 or $0 until one admin proposes a limit and a second approves it (approval kind `credit_limit`, audited). An allowance run, and its preview, refuses with INSUFFICIENT_FUNDS when it would take the account below minus the limit, and says what the account holds, the limit, and what the run needs. The check and the payments run under one lock per institution, so two runs cannot both pass on the same headroom. Payouts (T-0527) keep never going below zero: the credit line pays students, not suppliers. The tests cover: ₪1,000 held with a ₪5,000 limit refuses a ₪7,000 run and pays a ₪6,000 one, leaving −₪5,000; without an approved limit, a run larger than the balance is refused; one admin's proposal changes nothing; two concurrent runs on the last headroom pay once.
