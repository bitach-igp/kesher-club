## As built
- `/roster` (nav "Roster", for every staff role) shows a table: name (linking to I06 at `/roster/{id}`), status,
  cohort, card state, balances from bigint per locale, and plan. Status and cohort filters run as a GET form;
  anything the API would refuse is dropped before the call. "Next page" keeps the filters.
- **Selection.** Checkboxes select rows; the selection survives paging (kept in this browser tab's session storage)
  and clears once a placement lands.
- **Place in cohort.** Places the selection in one all-or-none call through the T-0636 API. The result reads
  "3 placed." or "2 placed; 1 were already in that cohort.", and a retry of the same cohort and students keeps its
  Idempotency-Key.
- **Resend invite is not here.** The card asked for a bulk "Resend invite" through the existing invite path, but
  that path has no HTTP endpoint: the reminder is the API's internal sweep (T-0602). A resend endpoint is an API
  change, so it stays out of this console card and is noted as a follow-up.
