Status: Proposed · Decide by: Sprint 1

## Context
See the live spec, Tab 3 §4.

## Options
- Tamagui vs NativeWind

## Recommendation (draft, 2026-10-18, for Zvi to accept or amend)
The house component set in `apps/mobile/src/components` over the Style Dictionary tokens (T-0006),
as built: about thirty components, every screen in M01 to M34 renders from them, and no screen names
a colour or a spacing value. Neither Tamagui nor NativeWind earns a migration now: both would re-skin
working screens for a styling API the team does not need yet. The test of this recommendation is the
Hebrew/RTL and Dynamic Type pass (T-0013); if the house set cannot pass it without a rewrite, reopen
this ADR with that evidence.
