# ADR-006: Card processor + sponsor bank

Status: Proposed · Decide by: Dec 2026

## Context
See the live spec, Tab 3 §4.

## Options
- Licensed program manager or BaaS that carries the compliance program (ADR-012)
- Shortlist: Nium (if it accepts US consumer prepaid), Synctera, a Marqeta- or Galileo-led program manager
- Ask each: sponsor bank and its enforcement history (CFSB consent order Apr 2026), Apple/Google Pay push provisioning, ACH/card/wire loads, P2P cost, institution→student hierarchy, minimums and reserves
- Gate: written acceptance of a parent-funded student program + counsel opinions

## Decision
Vendor: _pending_ (Money20/20 shortlist above).

Build decision (Zvi, 2026-10-17): E04 and E05 are built now against the CardIssuing, Funding, Fx,
Payout and KYC simulators behind their ports (cards T-0401–T-0408, T-0501–T-0511). The vendor
adapter is one later card per port and must pass the same contract suites; no domain, API or UI code
changes when it lands. Money flags stay `false` until the vendor adapter and the release gates are green.
