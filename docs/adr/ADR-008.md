# ADR-008: Outbound webhooks

Status: Proposed · Decide by: Sprint 8

## Context
See the live spec, Tab 3 §4.

## Options
- Svix vs in-house Standard Webhooks

## Recommendation (draft, 2026-10-18, for Zvi to accept or amend)
In-house Standard Webhooks, as built (T-0803, REQ-NOT-002): signing, the retry ladder (5 s to 24 h
over 72 h) and the replay UI exist and are tested. Svix would buy a hosted dashboard and endpoint
management for the integrating institutions; with the first integrating institution still to come
(`webhooks.outbound` is off), that is a cost without a customer. Revisit at five integrating
institutions or the first request for a self-serve endpoint portal, whichever comes first.
